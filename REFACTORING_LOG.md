# Журнал рефакторинга

> Примечание: это учебный журнал этапов для разбора. История Git ниже фиксирует
> коммиты проекта; фактическое выполнение каждого этапа на исходном форке
> преподавателя нужно повторить отдельно, если это требуется правилами курса.

| Этап | Приём | Результат |
|---|---|---|
| 1 | Переименование | Используются говорящие имена `item`, `sell_in`, `quality`, `change` |
| 2 | Извлечение констант | Числа 0, 1, 2, 50 и имена специальных товаров вынесены в константы |
| 3 | Извлечение метода | Правила товаров вынесены в `_update_normal_item`, `_update_aged_brie`, `_update_backstage_passes` |
| 4 | Упрощение условной логики | Правила каждого специального товара сгруппированы в отдельном методе |
| 5 | Точка остановки | Выделенных методов достаточно для текущего числа видов товара; Strategy добавил бы классы и навигацию |

Перед каждым реальным коммитом запустите тесты: `python -m pytest -v`.
