# Gilded Rose — Lab 11

Проект выполнен на Python в рамках лабораторной работы №11 по рефакторингу малыми шагами.

## Структура проекта

- `gilded_rose.py` — реализация логики обновления товаров.
- `main.py` — запуск программы.
- `tests/` — автоматические тесты.
- `REFACTORING_LOG.md` — журнал рефакторинга.
- `GIT_HISTORY.txt` — история Git.

## Установка

```bash
python -m pip install -r requirements.txt
```

## Запуск тестов

```bash
python -m pytest -v
```

## Запуск программы

```bash
python main.py
```

## Цель работы

Изучить запахи кода, написать характеризующие тесты и выполнить рефакторинг с сохранением поведения программы.
