# Лабораторная работа №11 — Gilded Rose (Python)

Проект подготовлен для открытия в PyCharm.

## Состав проекта

- `gilded_rose.py` — основная реализация магазина.
- `tests/test_gilded_rose.py` — характеризующие тесты и проверки граничных значений.
- `main.py` — демонстрационный запуск.
- `requirements.txt` — зависимость pytest.

## Открытие в PyCharm

1. Распакуйте ZIP-архив.
2. В PyCharm выберите **File → Open** и укажите папку `GildedRose_Lab11_PyCharm`.
3. Создайте/выберите интерпретатор Python 3.10 или новее.
4. Откройте Terminal в PyCharm и выполните:

   ```bash
   python -m pip install -r requirements.txt
   python -m pytest -v
   ```

5. Для демонстрации запустите `main.py`.

## Запуск тестов

Из корня проекта:

```bash
python -m pytest -v
```

Ожидается: все тесты проходят. Количество тестов уточняется фактическим запуском.

## Проверка тестов намеренной ошибкой

Чтобы выполнить обязательную проверку полноты тестов из лабораторной:
1. Временно измените в `gilded_rose.py` правило изменения качества обычного товара.
2. Запустите `python -m pytest -v`.
3. Убедитесь, что соответствующий тест упал.
4. Верните исходный код и снова запустите тесты.
5. Не сохраняйте ошибочную версию в итоговом коммите.
